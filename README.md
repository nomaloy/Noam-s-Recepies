# המתכונים של נעם

אפליקציית מתכונים אישית (עברית / English) עם חישוב כמויות לפי מספר סועדים ומחשבון חלה.
אתר סטטי של קובץ אחד – אין צורך בבנייה או בשרת.

## העלאה ל־GitHub Pages
1. יוצרים מאגר חדש ב־GitHub (למשל `recipes`), ציבורי.
2. **Add file → Upload files** ומעלים את כל הקבצים מהתיקייה הזו (כולל `.nojekyll`).
3. **Settings → Pages**: תחת *Source* בוחרים `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`, ושומרים.
4. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/recipes/`.

## הוספה למסך הבית
- **iPhone:** פותחים את הכתובת בספארי ← שיתוף ← "הוספה למסך הבית".
- **Android:** פותחים בכרום ← תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".

## עדכון מתכונים
מחליפים את `index.html` בגרסה החדשה (Add file → Upload files, אותו שם קובץ) ו־GitHub Pages מתעדכן תוך דקה-שתיים.
המועדפים, השפה ומספר הסועדים נשמרים בדפדפן של כל מכשיר בנפרד.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה: כל המתכונים, העיצוב והקוד |
| `manifest.webmanifest` | שם, צבעים ואייקונים להתקנה כאפליקציה |
| `apple-touch-icon.png` | אייקון למסך הבית באייפון |
| `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | אייקונים לאנדרואיד ולדפדפנים |
| `.nojekyll` | אומר ל־GitHub Pages להגיש את הקבצים כמו שהם |
